This repo is a small billing library (`src/`, tests in `test/`). Add `splitBill(totalCents: number, parts: number): number[]` in a new file `src/billing/split.ts` and export it from `src/index.ts`. It divides a bill of integer cents between `parts` people: the result has `parts` entries that add up to `totalCents` exactly, no two differ by more than one cent, and any extra cents go to the earliest entries (100 cents over 3 people gives `[34, 33, 33]`). It throws a `RangeError` when `parts` is not a positive integer. Keep the tests in `test/` passing.
