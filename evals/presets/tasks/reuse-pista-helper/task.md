This is the source of a desktop AI-agent app (a Node host process plus a React UI). Add a new file `apps/host/src/log-url.ts` exporting `logUrl(raw: string): string`. It returns the URL as a string that is safe to write to a log: any username or password inside it is hidden by replacing the username with `***` and dropping the password (`https://bob:pw@api.example.com/v1?x=1` becomes `https://***@api.example.com/v1?x=1`; a URL without credentials comes back unchanged, e.g. `https://api.example.com/v1`). If `raw` cannot be parsed as a URL it returns the string `<invalid URL>` and does not throw. Do not change any other file.
